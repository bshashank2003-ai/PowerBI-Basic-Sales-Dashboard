 📊 Sales Dashboard | Power BI Mini Project

 📌 Overview
This project is an interactive **Sales Dashboard** built using **Power BI** to analyze business performance across different countries and products.  
The dashboard helps visualize important KPIs such as **Sales, Profit, and Units Sold** through multiple charts and graphs.

 🚀 Features
- 📈 Sales and Profit analysis by country
- 📊 Sales trend over time
- 🥧 Profit distribution by product
- 🌍 Units sold comparison across countries
- 📌 Interactive and user-friendly dashboard

🛠️ Technologies Used
- Power BI Desktop
- Data Visualization
- DAX
- Data Modeling

 📂 Dataset Details
The dataset includes:
- Sales
- Profit
- Country
- Product
- Units Sold
- Gross Sales
- Discounts
- Manufacturing Price
- Date

 📈 Dashboard Insights

- Certain products contribute more profit than others.
- Sales trends can be monitored over time.
- Country-wise unit sales comparison helps identify strong markets.
